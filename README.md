# Simple Interest Calculator

A simple Python program that calculates simple interest based on principal amount, rate of interest, and time period.

## Formula

Simple Interest (SI) = (P × R × T) / 100

Where:
- P = Principal amount
- R = Rate of interest (in %)
- T = Time period (in years)
