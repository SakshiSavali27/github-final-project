# Contributing to Simple Interest Calculator

We welcome all types of contributions to this project, including:

- Bug reports
- Bug fixes
- Documentation improvements
- Enhancements
- Ideas

All contributions, big or small, are welcome and appreciated!

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and commit them with a clear message.
4. Submit a pull request describing what you changed and why.

## Reporting Bugs

If you find a bug, please open an issue describing the problem, steps to reproduce it, and the expected behavior.

## Suggesting Enhancements

Have an idea to improve this project? Open an issue describing your enhancement or idea, and we'll be happy to discuss it.

Thank you for contributing!
